Móng Nông trên Nền Tự Nhiên

Theo giáo trình Nền móng V08: kiểm tra sức chịu tải nền (TTGH1), tính lún (TTGH2), kiểm tra chọc thủng và tính thép đáy móng. 6 bài · 3 dạng A/B/C.

Số thứ tự của bạn: –

6 bài của CLO2

1
SCT móng băng — Nd1, B′, Rd, U
2
SCT móng đơn lệch tâm — Beff, Leff, ξ
3
SCT lớp yếu / đệm cát — khối quy ước 8°
4
Lún (TTGH2) — cộng lún từng lớp
5
Chọc thủng — F, u, Fb,u
6
Thép đáy móng — M, As, μ, khoảng cách

Lý thuyết tham khảo — công thức V08

1. Hằng số dùng chung (cấp hậu quả C2)
γn = 1,15 · γc = 0,9 (đất dính) · γf = 1,1 (TTGH1), 1,0 (TTGH2) · γtb = 20 kN/m³ · góc phân tán 8°
2. Sức chịu tải nền — TTGH1 (V08 mục 2.4.3)
γn·Nd1 ≤ γc·Rd   (2.4) ;   U = γnNd1/(γcRd)
Rd = B′L′·(Nγξγb′γ + Nqξqγ′hm + Ncξcc)   (2.15)
B′ = B − 2eB, L′ = L − 2eL ; Beff = min, Leff = max   (2.14, 2.20)
Nq = tan²(45° + φ/2)eπ tanφ ; Nc = (Nq − 1)cotφ ; Nγ = 1,5(Nq − 1)tanφ   (2.16–2.18)
ξγ = 1 − 0,25η ; ξq = 1 + 1,5η ; ξc = 1 + 0,3η, η = Beff/Leff (móng băng: ξ = 1)   (2.19)
3. Lớp yếu / đệm cát — khối móng quy ước
B″ = Beff + 2H·tan8° ; L″ = Leff + 2H·tan8°
Nd,yếu = N0 + γf(γtbhm + γuH)B″L″ ; q2 = γ0hm + γuH ; Rd theo (2.15) với thông số lớp yếu
4. Lún — TTGH2 (V08 mục 2.4.4)
p0 = p − σzg,0 ; σzp = α·p0 ; hi ≤ 0,4b ; dừng khi σzp ≤ 0,2σzg
S = β·Σσzp,i·hi/Ei, β = 0,8   (2.51–2.55)
5. Chọc thủng và thép đáy móng (V08 mục 2.5)
p = N0/(BL) ; F = N0 − p(lc + 2h0)(bc + 2h0) ; u = 2(lc + bc) + 4h0 ; F ≤ Rbt·u·h0   (2.75–2.77)
M = p·B·lx²/2 (đúng tâm) hoặc B·lx²(pmax/3 + p1/6) (lệch tâm) ; As = RbBξh0/Rs, ξ = 1 − √(1 − 2αm)   (2.93–2.94)

Lưu ý: tải N₀ (kN hoặc kN/m), mô men (kN·m), kích thước (m). Hệ số Nγ, Nq, Nc tính từ công thức, làm tròn 2 chữ số thập phân.
